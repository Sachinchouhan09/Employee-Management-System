# Employee Management System

A simple Employee Management System made using React, Node.js, Express.js and MongoDB.

## Features

* Add Employee
* View Employees
* Edit Employee
* Delete Employee
* Search Employee
* Sort Employees

## Technologies

* React.js
* Node.js
* Express.js
* MongoDB
* CSS

## Run Project

### Backend

```bash
npm install
npm start
```

### Frontend

```bash
npm install
npm run dev
```
